Tiny Compiler in Java

A three-chapter exploration of constructing a BASIC-dialect compiler in Java targeting C, adapted and expanded from Austin Henley's Teeny Tiny Compiler.

Introduction

This is a three-chapter journey documenting my experience building a compiler in Java. I took heavy inspiration from Austin Henley’s seminal project of the same name—the key distinction being that his was written in Python, while this implementation explores the nuances, structural guarantees, and verbosity of modern Java.

I highly recommend reading Austin Henley’s original articles for anyone interested in writing their first compiler. This series serves as an analytical companion: examining the trade-offs of Java's strict typing, string manipulation differences, and my commentary as the compiler evolved.

Building this project clarified much of the internal engine that powers modern programming languages: how grammar trees are formed, how tokens are dispatched, and how simple code generation transforms logic into machine-ready C.

Technical Disclosures

We implement a language dialect identical to Henley’s—a BASIC-style syntax—and our compiler emits C code, which can then be compiled into a native binary via GCC or Clang.
